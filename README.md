# Patient Management System

The **Patient Management System** is a simple web application built using Flask. It allows users to register, view, edit, and delete patient records. The application also includes a dashboard to display all patient data.

---

## Features

- **Patient Registration**: Add new patients with details such as name, mobile number, sex, and age.
- **View Patients**: Display a list of all registered patients.
- **Edit Patient Records**: Update patient details.
- **Delete Patients**: Remove patient records from the database.
- **Dashboard**: View all patient records in a tabular format.

---

## Prerequisites

Before running the application, ensure you have the following installed:

- Python 3.7 or higher
- Flask
- SQLite (comes pre-installed with Python)
